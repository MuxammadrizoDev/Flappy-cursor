✨ Features

Zero Dependencies: No heavy game engines installed. Just download the 18 KB .exe and play instantly.

Extremely Optimized: Consumes less than 5 MB of RAM while running.

Transparent Overlay: Uses native Windows API (user32.dll) to render a transparent, click-through window directly over your desktop.

Custom Physics Engine: Built-from-scratch 60-FPS physics system escaping the standard integer grid for smooth, decimal-based floating jumps and gravity.

🕹️ Controls

Spacebar / W / Up Arrow: Jump

Escape: Pause the game

🛠️ Tech Stack

Language: C#

Framework: Windows Forms (.NET)

OS Integration: Native Win32 API Interop (GetWindowLong, SetWindowLong for transparency and layering)

🚀 How to Run Locally (For Developers)

Clone this repository.

Open the .sln file in Visual Studio.

Build the project in Release mode.

Run the resulting .exe from the bin/Release/ folder.
